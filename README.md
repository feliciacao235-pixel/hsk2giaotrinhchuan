# HSK2 NABI Web App

Web App hoc HSK2 theo huong data-driven.

## Trang thai hien tai

- Da tao kien truc dung chung.
- Da nap du lieu chi tiet Bai 1.
- Bai 2-15, On tap 1 va On tap 2 dang khoa cho den khi giao vien duyet cau truc Bai 1.

## Telegram tren Netlify

Dat hai bien moi truong trong Netlify:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

Frontend se goi Netlify Function `/.netlify/functions/sendTelegram`, khong luu bot token trong trinh duyet.
